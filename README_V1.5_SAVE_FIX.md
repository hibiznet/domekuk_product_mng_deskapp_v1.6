# 도매꾹 상품관리 데스크톱 앱 V1.5 - 저장 방식 수정

## 핵심 변경
1. 상품 추가 시 DB INSERT를 즉시 실행하지 않습니다.
2. 상품 입력/수정은 메모리에서만 변경되고 `저장` 버튼을 눌렀을 때 DB에 반영됩니다.
3. 기존 상품 수정도 저장 버튼을 눌렀을 때 UPDATE됩니다.
4. 상품 삭제도 저장 버튼을 눌렀을 때 실제 DB DELETE가 실행됩니다.
5. 새 상품을 여러 칸 입력하는 동안 여러 INSERT가 발생하던 기존 중복 생성 버그를 제거했습니다.
6. 창을 닫을 때 저장되지 않은 데이터가 있으면
   - 저장하고 종료
   - 저장하지 않고 종료
   - 취소
   를 선택할 수 있습니다.
7. 연도/카테고리 이동, 엑셀 가져오기, 백업, 엑셀 다운로드 전에 저장되지 않은 변경사항을 확인합니다.
8. Electron 기본 File/Edit/View/Window 메뉴를 숨깁니다.

## 중요한 점
V1.4 이하에서 이미 DB에 생성된 중복 데이터는 기존 DB 레코드이므로 V1.5가 자동으로 삭제하지 않습니다.
기존 DB의 테스트 중복 데이터는 백업 후 별도 정리하는 것이 안전합니다.

## 실행
```powershell
npm install
npm run dev
```

Node.js 20.x 환경을 권장합니다.
